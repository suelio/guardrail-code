Varredura local rápida

Analisa segredos, bancos SQLite em pastas públicas, código Python via AST e notebooks Jupyter com limpeza explícita de RAM após cada execução.

Git, PyPI e OSV.dev

Audita e protege seu .gitignore com confirmação prévia, valida pacotes contra alucinações no PyPI e consulta vulnerabilidades conhecidas na API OSV.dev.
